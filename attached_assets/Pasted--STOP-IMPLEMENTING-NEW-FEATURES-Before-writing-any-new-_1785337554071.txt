# STOP IMPLEMENTING NEW FEATURES

Before writing any new code, stop and review the current implementation.

The application logic is acceptable.

The document rendering and printing engine is NOT acceptable.

We must completely redesign the document rendering system.

==================================================

CRITICAL REQUIREMENT

The uploaded Microsoft Word templates are NOT design references.

They are the OFFICIAL MASTER TEMPLATES.

Treat them as engineering drawings.

Your job is NOT to redesign them.

Your job is to reproduce them with the highest possible visual accuracy.

The goal is that the generated document and the original Word document look visually identical when placed side by side.

Target similarity:

100%

==================================================

DO NOT USE RESPONSIVE DESIGN INSIDE DOCUMENTS

The application pages can be responsive.

The printable documents must NEVER be responsive.

Each printable document is a fixed canvas.

Exactly like Microsoft Word.

Nothing should move.

Nothing should resize.

Nothing should wrap differently.

==================================================

DOCUMENT SIZE

Every printable page MUST be a real A4 page.

Width:

210 mm

Height:

297 mm

Never approximate.

Never use percentages.

Never use auto sizing.

Never let browser layout determine dimensions.

==================================================

USE MILLIMETERS

All printable templates must use millimeters instead of pixels whenever possible.

Example:

width:210mm;

height:297mm;

margin:0;

padding:0;

==================================================

PRINT LAYOUT

Do NOT build the page as a normal HTML page.

Instead build a Print Template Engine.

Each template should behave like a Microsoft Word page.

Use a dedicated printable container.

All elements must have fixed positions.

==================================================

NO FLEXBOX FOR DOCUMENT LAYOUT

Do NOT use Flexbox.

Do NOT use CSS Grid.

Do NOT rely on responsive alignment.

For printable templates use fixed positioning whenever necessary.

Every block must remain exactly where it exists in the original document.
